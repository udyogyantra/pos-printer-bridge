# Resoee POS Printer Bridge

Installers for **Resoee Print Bridge**, the small Windows program that lets the Resoee POS print receipts and kitchen tickets on the till's printers and open the cash drawer.

## Download

**[resoee-pos-printer-bridge-setup.exe](https://github.com/udyogyantra/pos-printer-bridge/releases/latest/download/resoee-pos-printer-bridge-setup.exe)**: always the latest version. Older versions are under [Releases](https://github.com/udyogyantra/pos-printer-bridge/releases).

## Install

1. Run the installer on the till. It needs no administrator rights.
2. If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. The installer is not code-signed yet.
3. Resoee Print Bridge starts by itself, and again every time Windows starts.
4. In the Resoee POS, open **Printing settings**, choose **Resoee Print Bridge**, and pick the printers.

Resoee Print Bridge is made by UdyogYantra. It is based on Thermal Bridge by XenithPulse, used under the MIT licence, which is included with every installer.
